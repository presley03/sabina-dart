## 1. Pengenalan

SABINA ("Aplikasi", "kami") adalah aplikasi mobile yang didedikasikan untuk memantau kesehatan ibu hamil. Kami sangat menghargai privasi Anda dan berkomitmen untuk transparan tentang bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi kesehatan Anda.

Kebijakan Privasi ini menjelaskan praktik data kami dan hak Anda. Silakan baca dengan cermat.

---

## 2. Informasi yang Kami Kumpulkan

### 2.1 Informasi Identitas
Informasi yang Anda masukkan secara langsung:
- Nama lengkap
- Tanggal lahir
- Alamat tempat tinggal
- Golongan darah
- Agama
- Foto profil (opsional, disimpan lokal di perangkat)

### 2.2 Informasi Riwayat Kehamilan
- Tanggal hari pertama haid terakhir (HPHT)
- Berat badan dan tinggi badan sebelum hamil
- Urutan kehamilan (kehamilan ke-)
- Jumlah anak
- Riwayat keguguran
- Data persalinan sebelumnya (berat lahir, cara persalinan, penolong, komplikasi)

### 2.3 Hasil Skrining & Kuesioner
- Jawaban dan hasil kuesioner preeklampsia
- Hasil penapisan faktor risiko kehamilan
- Hasil kuesioner keluhan: mual muntah, sakit kepala, keluar darah, keluar cairan, bengkak, pergerakan janin
- Tanggal dan waktu pemeriksaan
- Tingkat risiko hasil (rendah/sedang/tinggi)

### 2.4 Data Teknis
- Preferensi bahasa aplikasi
- Versi aplikasi yang digunakan

---

## 3. Cara Data Disimpan

**SABINA menyimpan semua data sepenuhnya di perangkat Anda (lokal).**

| Jenis Data | Media Penyimpanan | Enkripsi |
|-----------|-----------------|---------|
| Identitas & riwayat kehamilan | SQLite (lokal) | Perangkat |
| Hasil skrining & kuesioner | SharedPreferences (lokal) | Sistem OS |
| Health records, kontak darurat | Secure Storage (Keychain/Keystore) | AES enkripsi |
| Foto profil | Direktori dokumen aplikasi | Perangkat |
| Preferensi bahasa | SharedPreferences (lokal) | — |

**Kami TIDAK mengirim data Anda ke server eksternal manapun.**
**Kami TIDAK menggunakan layanan cloud pihak ketiga untuk menyimpan data kesehatan Anda.**

---

## 4. Cara Kami Menggunakan Informasi

Informasi yang Anda berikan digunakan **hanya** untuk:

✅ Menampilkan informasi kesehatan yang personal dan relevan
✅ Menghitung usia kehamilan real-time dari HPHT
✅ Menghitung usia Anda dari tanggal lahir
✅ Menampilkan riwayat hasil skrining di profil Anda
✅ Memberikan rekomendasi berdasarkan hasil kuesioner
✅ Menyesuaikan konten artikel dan panduan per trimester

### Kami TIDAK Akan
❌ Menjual data pribadi Anda kepada pihak ketiga
❌ Membagikan data kesehatan Anda kepada siapapun
❌ Menggunakan data untuk tujuan iklan atau komersial
❌ Melacak lokasi Anda
❌ Mengakses kamera/mikrofon tanpa izin Anda

---

## 5. Berbagi Data

SABINA **tidak** membagikan data Anda kepada pihak ketiga manapun. Semua data tetap berada di perangkat Anda.

Pengecualian satu-satunya adalah jika Anda secara aktif memilih untuk berbagi informasi (misalnya, menghubungi tenaga kesehatan melalui WhatsApp menggunakan tombol konsultasi di aplikasi) — dalam hal ini tindakan berbagi sepenuhnya ada di kendali Anda.

---

## 6. Keamanan Data

### Penyimpanan Lokal
- Database SQLite tersimpan di direktori privat aplikasi, tidak dapat diakses aplikasi lain
- Secure Storage menggunakan Android Keystore / iOS Keychain untuk enkripsi hardware-level
- Foto profil tersimpan di direktori dokumen aplikasi (tidak dapat diakses aplikasi lain)

### Keamanan Perangkat
Keamanan data Anda juga bergantung pada keamanan perangkat Anda. Kami menyarankan:
- Aktifkan kunci layar (PIN, pola, sidik jari)
- Perbarui OS perangkat secara rutin
- Jangan berikan akses perangkat kepada orang yang tidak dipercaya

---

## 7. Retensi Data

Data Anda tersimpan di perangkat selama Anda menggunakan aplikasi.

**Menghapus data:**
- Uninstall aplikasi → semua data terhapus otomatis
- Data di Secure Storage dapat tersisa, hapus manual via Settings perangkat jika diperlukan

---

## 8. Hak Anda

Anda memiliki kendali penuh atas data Anda:

- **Akses**: Semua data dapat dilihat langsung di aplikasi (Profil, Riwayat Kehamilan, Hasil Skrining)
- **Koreksi**: Edit data kapan saja melalui menu Identitas atau Riwayat Kehamilan
- **Penghapusan**: Uninstall aplikasi untuk menghapus semua data
- **Portabilitas**: Data Anda tersimpan lokal dan tidak terkunci di cloud manapun

---

## 9. Privasi Anak-Anak

Aplikasi ini diperuntukkan bagi **wanita hamil dewasa (18+ tahun)**. Kami tidak secara sadar mengumpulkan data dari anak-anak di bawah 18 tahun sebagai pengguna utama.

---

## 10. Disclaimer Medis

🚨 **PENTING**: SABINA adalah **alat bantu monitoring kesehatan**, bukan pengganti konsultasi medis profesional.

- Hasil skrining dan kuesioner dalam aplikasi ini **bukan diagnosis medis**
- Selalu konsultasikan kondisi Anda dengan dokter kandungan atau bidan
- Untuk kondisi darurat, segera hubungi **118** atau kunjungi fasilitas kesehatan terdekat
